# ズボラさんのなんとなく趣味プランナー

趣味と自由時間を入れるだけで、なんとなくの週間プランを提案してくれる、多趣味サポートアプリです。

「趣味がたくさんあって時間が足りない」「時間割を決めるのが面倒」という人向けに、唯一の正解を計算するのではなく、**5パターンの時間割案**を提示し、気に入ったものを選んで使う形式をとっています。

公開URL：https://tashumi-support-app.onrender.com

---

## 主な機能

- ユーザー登録・ログイン
- 趣味の登録と、円グラフでの時間配分（％）調整
- 1週間の自由時間を、曜日ごとに15分刻みで入力
- 入力内容をもとに、5パターンの週間スケジュール案を自動計算・提示
- 気に入ったパターンをお気に入り保存し、TOPページでいつでも確認

---

## 競合との差別化

「1日単位のスケジュール」を組む既存サービスとは異なり、本アプリは**毎週の自由時間に限った趣味の割り振り**に特化しています。ユーザーがやることは「自由時間の入力」と「趣味の時間配分（％）を決める」だけ。唯一の正解を計算するのではなく、**複数パターンの時間割案を提示**し、参考にして選んでもらう形式です。

---

## 使い方

1. 時間を割きたい趣味を、円グラフに入れたいだけ入れる
2. 円グラフ上で、それぞれの趣味に割きたい時間の配分（％）を決める（合計100%になるよう自動調整）
3. 1週間の自由時間を、曜日ごとに15分刻みで入力する
4. 自由時間の実際の値をもとに、曜日への配分の仕方が異なる5パターンの時間割案を自動生成
5. 5パターンをキャッチコピーと一緒に見比べ、気に入ったものを選ぶ
6. 選んだスケジュールが保存され、TOPページでいつでも確認できる

---

## 入力項目の検討内容

ユーザー操作を「自由時間」「趣味の配分％」の2つだけに絞り込んでいます。円グラフは100%からスタートし、趣味を登録するたびに自動で割り振られるため、手動で合計を100%に揃える必要はありません。

以前検討していた「頻度」「曜日・配分の偏り」「最低確保時間」「最大時間（上限）」といった個別設定項目は、いずれも見送りました。理由は、ユーザー操作を最小化する方針への転換に加え、「複数パターン提示→選んでもらう」という本アプリの設計思想と役割が重複すること、ズボラ層にとって入力動機が弱く使われない可能性が高いことなどです。これらは、リリース後のユーザーの声次第で将来的に再検討する可能性があります。
